# Figure Studio — Android local development preview

This is a development APK for testing the existing local editor on Android. It bundles the complete browser UI and pinned scientific WebAssembly runtime. Analysis, chart generation and image screening run inside an on-device Web Worker. The 0.1.18 development preview permits the optional Europe PMC search only when explicitly started, sending chart terms and an optional typed topic, not research data. The APK requests Internet permission for this lookup; update checks fetch only official GitHub version metadata without research data, and local calculation remains available offline. It uses one stable private origin (`https://appassets.androidplatform.net/assets/www/`), so app updates using the same application ID and signing key preserve WebView storage. Uninstalling the app clears that storage; save project files as separate backups.

The development build requires Android 8 or later and a current Android System WebView with Web Message Listener, WebAssembly, Workers, IndexedDB and modern JavaScript support. Android version alone does not guarantee these browser capabilities. The shell shows an explicit update notice when the required native messaging feature is unavailable. Device performance and low-memory behavior must be measured on each target class; an emulator pass is not a phone/tablet performance claim.

## Install and use

Download the tested **Figure-Studio-Android-Local-Preview.apk** CI artifact, allow installation from the chosen download/file app when Android requests it, and open Figure Studio Preview. No Python, Codex, account or server is required. This APK is signed with a development/debug key, not a Play Store production release. A different CI debug key may require uninstalling the previous development APK; export projects before replacing it. Production signing and store delivery are separate work.

Use the editor's import/open command to select local files. The system document picker is limited to local providers when the platform honors `EXTRA_LOCAL_ONLY`. Native export stages at most one file, streams chunks of at most 192 KiB, then opens the system save dialog. The 200 MB limit applies to a single export. The editor receives “saved” only after the destination stream has been written and closed. Cancelling remains cancellation. The app's abandoned staging files are removed on the next start. Selected input files are never rewritten.

The underlying local-browser prototype does not import editable PDF files. Existing source-image, statistics and image-screening limits still apply. SVG/PNG/TIF, projects and reports use the same editor export methods; the native adapter preserves generated bytes without image recompression. The calculation engine falls back explicitly to bundled fonts where necessary; imported artwork is not silently converted.

## Reproduce the development build

Use JDK 17, Gradle 8.11.1, Android SDK 35/build-tools 35.0.0, Node.js 22 and Python 3.12. The build downloads only public developer dependencies, never research inputs.

```sh
npm install --prefix .cache/mobile-local-spike --cache .cache/mobile-local-spike/npm-cache --ignore-scripts --no-audit --no-fund pyodide@0.29.3
node web/prepare-runtime.mjs
python mobile/android/prepare_assets.py
node --test mobile/android/test_bridge.cjs
python mobile/android/test_assets.py
gradle -p mobile/android --no-daemon testDebugUnitTest verifyDebugApkAssets assembleDebugAndroidTest
adb install mobile/android/app/build/outputs/apk/debug/app-debug.apk
adb install mobile/android/app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w -e class org.polishscifigures.studio.preview.LocalEngineInstrumentedTest org.polishscifigures.studio.preview.debug.test/androidx.test.runner.AndroidJUnitRunner
adb shell am force-stop org.polishscifigures.studio.preview.debug
adb shell am instrument -w -e class org.polishscifigures.studio.preview.WorkspaceRestartInstrumentedTest org.polishscifigures.studio.preview.debug.test/androidx.test.runner.AndroidJUnitRunner
```

`prepare_assets.py` rebuilds the current public browser bundle, verifies its file checksums and copies only named public assets into the generated APK asset folder. It refuses to replace an unmarked folder. Gradle verifies the manifest before packaging and checks every public file and license inside the completed APK, including dependency notices in underscore-prefixed folders. `.github/workflows/android-local-preview.yml` builds and runs an Android 35 emulator, retaining the debug APK only after successful instrumentation.

The runtime test uses a fresh emulator profile, synthetic data and a test-only document provider. It checks an actual WebView file chooser and file read, actual provider output bytes and cancellation, IndexedDB project JSON after Activity recreation, a real editor alignment-guide change restored from autosave with undo history after a separate process restart, real SciPy Welch calculation, Matplotlib SVG generation and native export, and resource-access restrictions. The [recorded earlier APK](../../docs/mobile-preview-validation.md#android-verified-native-runtime) had no Internet permission; that result does not validate the new optional literature connection. Display/density overrides exercise tablet-sized portrait and landscape viewports and retain screenshots. These are emulator display tests, not physical-tablet performance measurements. Espresso supplies the system picker's selected URI; the provider write is real. It does not claim to have manually navigated every vendor's Files app or tested real low-end devices. The binary TIFF transport fixture verifies byte preservation and is not itself a generated scientific TIFF. Tests refuse an already edited workspace and never clear existing project/autosave databases.

Implementation references: [Android local WebView content](https://developer.android.com/develop/ui/views/layout/webapps/load-local-content), [WebViewAssetLoader](https://developer.android.com/reference/androidx/webkit/WebViewAssetLoader), [WebViewCompat messaging](https://developer.android.com/reference/androidx/webkit/WebViewCompat), [Storage Access Framework](https://developer.android.com/training/data-storage/shared/documents-files).

CI environment note: the first Android 35 Google image showed a “Pixel Launcher isn't responding” system dialog over a responsive editor after successful editor autosave restoration. The dedicated emulator now disables only that Google Home launcher package before explicitly launching instrumentation. Application ANR dialogs are not suppressed. This setup does not verify launcher-home-screen interaction; installation and app launch are performed through ADB/instrumentation.

## Android 本地开发预览版

这是用于实际验证的开发 APK，内置完整界面与固定版本的科学计算运行库。统计、作图、图片查重均在设备本地执行；安装后不需要 Python、Codex、账号或远程计算服务器。0.1.18 开发预览版允许用户主动启动可选的 Europe PMC 检索，只发送图型词和手动填写的主题，不发送研究数据；APK 因此需要互联网权限，更新检查只读取 GitHub 官方版本信息，不发送研究数据；本地计算仍可离线使用。要求 Android 8 及以上，并使用支持所需功能的较新 Android System WebView。系统版本不能代替 WebView 能力或真实设备性能验证。

从成功通过测试的 CI 附件中下载 APK，按 Android 的提示允许当前下载/文件应用安装，然后打开 Figure Studio Preview。这是使用开发密钥签名的测试版，并非应用商店正式版；不同 CI 构建的开发密钥可能不同，替换旧测试版前先导出工程备份。卸载会清除应用内存储，同一应用 ID 与签名的正常更新则保留本地存储。

导入使用系统本地文件选择器；导出按每块最多 192 KiB 分块传递，单个文件不超过 200 MB。用户选择保存位置、文件完整写入并关闭后才显示成功；取消保存不会误报成功。输入文件不会被覆盖，导出暂存文件在完成或取消后删除，异常中断遗留文件下次启动时清理。SVG、PNG、TIF、工程和报告由原有编辑器生成，原生适配器只保存字节，不额外压缩图像。

本地浏览器原型的能力边界仍适用，包括暂不支持可编辑 PDF 导入。构建步骤见上方；`prepare_assets.py` 从当前源码重新构建公共资源并校验，只打包清单中的程序文件，不包含研究工程或测试证据。Gradle 还会逐项校验成品 APK 内的公共资源及许可证，保留下划线目录中的依赖许可说明。

自动化测试在全新的 Android 35 模拟器环境中使用合成数据，覆盖真实 WebView 文件选择回调与读取、系统文档接口写入和取消、页面重建后的 IndexedDB 工程 JSON、编辑器实际参考线操作在进程重启后的自动保存及撤销记录、实际统计与 SVG 出图、资源访问限制，并通过模拟器显示尺寸和密度设置检查平板横竖屏及截图。系统选择器的选择结果由测试框架提供，文件实际写入；这不等于已经人工验证所有厂商的文件管理器，也不代表低配置真机或真实平板的流畅度。二进制 TIF 传输用例验证字节不变，不冒充实际生成的科研 TIF。测试遇到已有编辑工程会停止，不清理用户工程库。开发预览完成测试后，仍需继续实测手机和平板。

CI 环境记录：首轮实际界面已成功恢复编辑器自动保存，但 Google 系统镜像的 Pixel Launcher 出现无响应弹窗并遮挡编辑器。专用模拟器现仅停用该系统桌面包，再由测试程序明确启动应用；没有屏蔽本应用的无响应提示。这一环境通过 ADB 安装和启动，不作为已经验证桌面图标交互的证据。
