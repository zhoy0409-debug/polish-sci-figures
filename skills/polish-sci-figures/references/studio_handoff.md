# Figure Studio handoff and editor rules

Read this before building, opening or returning to a Studio project, choosing a template for editing, or using the editor's image and axis tools.

## Product entry points

Supported builds also provide local **Submission profiles…** under submission size/export. Use requirements explicitly supplied by the researcher or a verified guideline, with source and date; do not invent journal dimensions from a profile name. Profiles use `figure-studio-submission-profile/1`, contain no artwork or measurement tables, and are validated on project open. Preview/Cancel/Keep reuse the editor transaction; final-size review uses the shared `figure-quality.js` rules with the declared thresholds and discloses width/DPI/height mismatches. See [the workflow and supported scope](../../../docs/figure-studio-submission-profiles.md).

This skill and Figure Studio are two entry points to the same product. The original AI/CLI workflow remains available; manual editing is optional. Figure Studio is the official Windows companion editor, not a fourth independently installed skill. For desktop editing, return the direct [Figure Studio Setup for Windows 10/11 x64](https://github.com/zhoy0409-debug/polish-sci-figures/releases/download/v1.6.2/polish-sci-figures-Studio-0.2.3-Setup-x64.exe). Double-click Setup, then open Figure Studio from the desktop or Start menu. The renderer and analysis engine work offline. For Claude or Codex, return the [AI Skill installation guide](https://github.com/zhoy0409-debug/polish-sci-figures/blob/main/docs/platform-installation.en.md) with the package, installation location and invocation for the requested host. Do not ask those users to set up an agent runtime.

When the user wants to continue in Figure Studio, deliver a project JSON from the reviewed source with `python sci_figures.py studio SVG_OR_BUNDLE --project-out figure-studio-project.json`. Tell the user to choose **Project → Open project** and select that file. For an existing project, preserve its sources, panel states and data bindings and apply only the requested scope. Offer a standalone page with `--out figure-studio.html` when the user also needs browser editing. Offline HTML supports direct layout and appearance editing; current-data regeneration and analysis require the local service. The installed desktop application starts this service automatically. Read [Figure Studio](figure_studio.md) for the actual contracts and [human/AI handoff principles](human_ai_figure_workflow.md) before returning to a saved project.

The editor must open on the final approved chart. For a candidate directory, pass `--view` with the chosen SVG filename stem, preserve its data and analysis records, and inspect the initial HTML alongside the final image. For an individually edited final SVG, package that exact SVG or update its bundle candidate first. One panel defaults to one column; extra blank cells require an intentional layout. Never substitute the default candidate for the user's final choice.

The suite retains MIT licensing and third-party notices. Official branding identifies the maintained distribution; it is not copy protection. Never add account gates, activation or an online authenticity check as part of ordinary figure delivery.

### Match the installed capability

Identify the platform, build and required feature before routing. Check the official release assets and the installed controls or local inspection capabilities. Record Windows installed, macOS native preview and shared browser-source checks separately. On a build that lacks a feature, continue locally with the bundled Python CLI or compatible browser editor when available. Preserve a saved project copy before testing a newer build.

For image sizing, use **Auto-fit to cell** for centered proportional placement. The drag controls separately offer Auto (corner handles preserve proportions), Locked and Free scaling. Use proportional placement for calibrated images. For a specific publication slot with width and height maxima, use the image workflow’s `--fit-box-mm` and inspect its achieved physical size, effective DPI and scale-bar alignment.

## Local image tools and professional axes

Figure Studio exposes the existing editing pipeline through five workflow entries and local command search (Ctrl/Command + K). Use **Image tools** for independent decorative borders, explicit local duplicate screening, original/adjusted display histograms and overview/detail source-coordinate refinement. Native axes re-render from real data; imported numerical axes retain only scientifically supported presentation changes. Do not invent a numerical mapping for flattened images or infer common image provenance from appearance alone.

The editor supports reversible real-canvas drafts. Keep borders, axes and image tools docked while adjusting; use their Apply/Keep or Cancel actions. Ordinary numeric properties preview while typing and keep one edit on Enter/blur; Esc restores the draft and its fields. Save/export use committed settings. Follow the [live editing guide](../../../docs/live-preview-editing.en.md); do not replace verified data rendering with simulated previews or infer specimen calibration from a screenshot. Check the installed editor version and capabilities before promising source-tree additions in an older release.

Duplicate detection and localization are engineering aids, not misconduct judgments. Heavy crops and low-information Western blot strips remain documented misses/refusals. Independent human-labelled blind accuracy is still unverified; keep private images and source paths local. A synthetic pass or transformed real-source regression cannot establish real-case sensitivity. Original pixels remain available, manual ROI confirmation is labelled explicitly, and reference display matching is not stain normalization or quantitative fluorescence correction. Use the bundled image-tool, axis and evaluation guides for limits and reproducible checks.

## Templates, candidates and statistics in the editor

- Treat gallery previews as scientific deliverables: inspect the rendered card, enlarged view and composite placement. A good chart type must not be discredited by a poor implementation. Reject clipped labels, overlapping annotations, distorted geometry and illegible detail before presenting a template as ready. Prefer faithful observations, distributions and effect estimates when they answer the user's question; chart novelty alone is not a recommendation criterion.
- For each new editable template, validate its original and replaced data, inspect normal, narrow, wide and tall renders, and exercise the studio data-engine round trip. Preview and applied output must share the renderer. Use native geometry for shape-dependent charts and real axis/layout reflow for size changes; never call affine stretching a responsive template.
- Absorb supplied galleries as design references and data contracts, then implement original renderers in the suite's visual language. Never substitute copied reference cards for editable templates. Label synthetic examples, distinguish implemented renderers from indexed backlog, and validate data replacement and undo as well as appearance. See `figure_studio.md` for the current original-template coverage.
- Rank statistical alternatives by the declared estimand, design, experimental unit and method assumptions, never by P value. Compare existing primary/sensitivity results with their own effect measures; retain every method considered and the user’s selection rationale. Missing paired, repeated, covariate or censoring information gates unsupported models. A global test cannot supply pairwise letters. Read the method-comparison section of `figure_studio.md`.
- Preserve bilingual UI selection, local autosaved undo/redo, named checkpoints, and intentional-save preference memory in interactive workflows. Never treat hovering or autosaving as aesthetic approval. For candidate-library expansion, read `chart_discovery_curation.md`; only offer scientifically suitable, actually rendered candidates.
- The current catalogue has 218 editable starters (191 gallery layouts and 27 ROC/PR presentations), not 218 statistical models. Use the matching input contract; supplied-model displays require actual results. Contract and geometry tests do not certify every possible dataset, label length or final composition as visually approved.
- Use direct character formatting for selected portions of existing or inserted text; preserve native italics and superscripts elsewhere. Numeric results edited as display text must remain marked manual and must not replace the analysis record. For true axis range, category gap or data-coordinate reference-line changes, use supported source redraw controls; changing a tick's text does not rescale an axis.
- Use the explicit local statistical-analysis workflow when comparison results are needed: require confirmed design and experimental-unit roles, choose the supported method by estimand, and retain the requested comparison family. Current-data bindings recompute after valid edits; external and split-facet snapshots become stale when their bound data change. Do not replace missing pairwise results with an omnibus P value.
- For interactive multipanel layout, offer master thumbnails, explicit rows × columns, spanning slots, and drag/keyboard position changes in Figure Studio. Use `--with-layouts` with supported workbench recipes and verified source data to prepare true portrait/wide redraws. Preview both the individual panel and its composite context. Never substitute SVG stretching or bitmap rotation for a layout-aware redraw; preserve manual choices and undo history.
- When the user wants direct visual editing after the AI first draft, read `human_ai_figure_workflow.md` and `figure_studio.md`, then build the offline editor with `scripts/figure_studio.py`. It accepts reviewed candidate directories or standalone SVG panels and supports selection-scoped colour/opacity/text edits, real candidate previews, undo/redo, named versions, and editable export. Keep the original AI-only workflow available. Never claim a flattened PNG is element-editable or that browser styling reruns statistics. Preserve the user's manual choices when resuming AI finalization.
- In the Windows 0.2.0 release, native TIFF import retains originals separately from real-canvas window/gamma/LUT displays. Read `../../../docs/figure-studio-native-tiff.md` for exact limits and the recorded installed-app scope. After import, **New display from original TIFF** rereads the retained native plane with existing display parameters prefilled, creating a separate display while preserving the previous image and manual edits. It does not transfer a derivative's correction or calibration. Ordinary post-import color adjustments do not re-read native intensity data. Large project save/parse uses local Workers and preserves later edits as unsaved.

## Final-size review and scoped project collaboration

Use the bundled Review workspace and [local operation protocol](project_operations.md) for final-size findings and targeted edits to a saved project. Preserve unrelated human edits; import operation files for atomic preflight and real-canvas preview instead of replacing the whole project. Do not infer statistics from a flattened figure. Capability availability in a source-tree candidate does not imply an older Windows installer contains it.

When asked to match the size and baseline of several panel labels, use the [reference-label operation](project_operations.md#match-several-panel-labels-to-one-reference) if advertised by the Studio inspection. Resolve letters using `displayLabel` and return one operation JSON for all specified targets.

## Colour vision, notation and text replacement

Source builds that bundle `figure-lens.js` add three tools to the Review workspace. Check that the controls exist before promising them in an installed release.

- **Colour-vision preview** shows the canvas as red-, green- or blue-blind readers see it, or in grayscale. It filters the screen only; projects and exports keep their colours.
- **Review current figure** also reports colours that merge in those views, mixed font families and baseline scientific notation. Colour findings ask whether colour carries the grouping; they never recolour data. **Preview notation fixes** changes plain display text in one undoable batch.
- **Find and replace text** (Ctrl/Cmd + H) searches every panel and text annotation literally and previews before Keep. Locked objects, statistical results and text with character formatting are listed but not replaced.
