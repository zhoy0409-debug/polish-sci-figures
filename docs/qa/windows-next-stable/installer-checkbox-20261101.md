在 [FigureStudio.iss](../../../desktop/FigureStudio.iss) 的初始化中，为 TasksList 和完成页 RunList 设置 DPI 缩放后的前导间距。使用官方支持的 [Offset 属性](https://jrsoftware.org/ishelp/topic_scriptclasses.htm)；该 setter 会重新测量项目并重绘，不改变勾选状态。没有改用假复选框、缩小字体、更改系统显示设置或移除桌面快捷方式选项。
