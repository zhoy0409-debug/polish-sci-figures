# 安装向导中文裁切修正

用户提供任务选项页的局部截图，并确认窗口正常宽、内部文字显示不全。本轮只修安装向导的字体、文案及说明布局；编辑器视觉与功能继续冻结，未合并或发布。

## 修改

- 简体中文采用 Microsoft YaHei UI，保留 9pt 字号；不要求用户缩小文字或关闭高 DPI。
- 窗口标题使用 Figure Studio，快捷方式页使用简短说明，避免把长仓库名反复嵌入提示。
- 开启说明换行；以实际已缩放的内容宽度计算任务说明高度，并只按高度差移动下方选项，避免返回页面时累计偏移。
- 向导宽度比例从默认120适度增至130，纵向保持120，保留 DPI 纵横比。不是只扩大外框或缩小字体。

这些使用 Inno 的[字体与语言设置](https://jrsoftware.org/ishelp/topic_langoptionssection.htm)、[窗口尺寸比例](https://jrsoftware.org/ishelp/topic_setup_wizardsizepercent.htm)、[DPI纵横比](https://jrsoftware.org/ishelp/topic_setup_wizardkeepaspectratio.htm)及[标准标签高度调整接口](https://jrsoftware.org/ishelp/topic_scriptclasses.htm)。编译工具为本机 Inno Setup 7.1.0；没有使用该版已移除的 WizardResizable。

关闭旧安装向导后，打开新候选。第一页应为“快捷方式”，两处说明及“创建桌面快捷方式”应完整显示；可先取消退出来检查排版，不必立即执行安装。是否显示完整、按钮是否可见、复选框是否能操作分别记录。
