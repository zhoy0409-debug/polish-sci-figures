# Windows 安装版协同验收 · 2026-11-01

本报告记录用户在 Windows 安装版中实际操作后的反馈，以及对安装文件和实际保存工程的独立只读核对。用户在完成下列检查后表示当前稳定，结束人工验收并明确授权发布。该授权改变发布决定，不把尚未执行的检查改为通过。

## 测试对象与证据

用户安装的是内部候选 wn26，Studio 0.2.0 / Suite 1.5.0。运行时冻结来源为 `819fe452d567e1e73dbc8736d10afaf0a0360269`，安装页修复提交为 `5cd02f1a118fbbde9d0ef130bbf7151b94fdd1e5`；该提交的 [8 项 CI 全部通过](https://github.com/zhoy0409-debug/polish-sci-figures/actions/runs/41225760535)。最终发行包只刷新文档和证据，编辑界面与原生程序沿用已验收代码；最终哈希及来源核对另附发行资产，不把 wn26 人工结果称为最终字节完全相同包的重测。

wn26 Setup SHA-256：`e95f4e8434bac9047764c7e68863ca536edc4c479c652b9f774766bdc6b2bc23`。Portable SHA-256：`f093252adf324ec2400c4ed15cc34ed9228f2297aba5b6acb5d1182fde5ca95a`。实际安装目录 2695 个程序文件与 Portable 的路径、尺寸、SHA-256 全部相同，缺失和差异均为 0。校验未修改用户安装目录、原图或工程。

人工操作由用户执行，通过聊天反馈结果。没有原生输入事件跟踪或本轮完整操作录屏，不推断未观察到的步骤细节。浏览器截图、冻结服务自检和合成数据只用于各自工程回归。

## 科研数据与实际保存文件

实际下载工程的 SHA-256 为 `8bee751bbd392de30b9e7b3ec72e92efd1cd1bc3aa221630c8a02c03815767b4`。对照公共 UCI Iris 输入（150 条观测；来源 DOI [10.24432/C56C76](https://doi.org/10.24432/C56C76)，CC BY 4.0），原始表、当前活动面板表、来源摘要和统计推断字段保留；全部 12 个原始 SVG 按索引、名称和尺寸逐份一致。

重绘建立新的活动面板，原面板保留。独立按新坐标范围计算全部 150 个点，实际 SVG 坐标最大误差为 `4.822804271498171e-7 pt`，低于 `2e-6 pt` 的数值容差。设置没有通过改刻度文字伪装重标定。

核对脚本的首次读取误将原面板当作活动面板而失败，第二次按重复图名建字典只计入 6 项；最终分别按活动顺序和全部 12 个索引校正。保留两次检查工具失败，不将其称为产品数据丢失。
