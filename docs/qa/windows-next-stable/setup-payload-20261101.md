## 可复现方法

维护者先在全新缓存目录离线解包，再用[核验命令](../../../scripts/verify_studio_setup_payload.py)比较解出的 `{app}` 目录与已锁定的 Portable。核验器不调用解包程序、不执行目标 EXE、不修改注册表，并拒绝覆盖既有报告。

本次使用[上游公开 CLI 资产](https://github.com/jrathlev/InnoUnpacker-Windows-GUI/releases/tag/ui_2_2_13)，下载字节与 GitHub 提供的 SHA-256 一致。资产说明写 2.71.2，实际命令行程序报告 2.71.3；记录以实际哈希和输出为准。工具仅在开发缓存使用，不加入 Figure Studio 安装包。

```powershell
# 在仓库根目录执行；先核实工具 SHA-256，再解包到一个尚不存在的目录。
<innounp.exe> -x -b -a -m -o -u -q -d<new-extraction-directory> <candidate-Setup.exe>
```

```powershell
python scripts/verify_studio_setup_payload.py --setup <candidate-Setup.exe> --portable <candidate-Portable.zip> --extracted-app <new-extraction-directory>/{app} --expected-setup-sha256 <approved-Setup-SHA256> --expected-portable-sha256 <approved-Portable-SHA256> --out <new-report.json>
```

准确包哈希在[本次 JSON](setup-payload-20261101.json)中。核验器先核对两个整包哈希，再比较每个文件的名称、大小和实际解压字节。它拒绝异常 ZIP 路径、大小写重名、符号链接及已解包树中的 Windows reparse point；不自动修复或删除可疑文件。

首轮受沙箱 TEMP 权限影响，未进入产品断言；仅将测试进程 TEMP/TMP 指向工作区后重跑。异常 ZIP 测试还发现 Windows `ZipInfo` 会规范化原始成员名，因此改为核对 `orig_filename` 并保留真正的异常夹具。失败批次均保留，没有降低断言。
