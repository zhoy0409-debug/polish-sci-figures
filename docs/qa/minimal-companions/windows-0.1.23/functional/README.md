Discovery uses repository synthetic tables and public Iris. It verifies independent previews, required unit confirmation, paired long-table conversion, occupied-panel append and blank replacement, Undo/Redo, Save/Open, SVG/PNG export and invalidation after design changes. The actual click using a local table value is rejected before a literature request. A separate public-keyword search is intercepted and aborted to exercise literature failure while retaining local previews; no paper or response is fabricated. No real patient data are used, and this is a bounded privacy-guard check rather than a comprehensive patient-identifier audit.

The standalone offline branch uses explicitly supplied packaged HTML, applies its declared summary data, checks the real saved payload and records zero HTTP requests. Installed online branches use the actual loopback engine without replacing its scientific responses.
