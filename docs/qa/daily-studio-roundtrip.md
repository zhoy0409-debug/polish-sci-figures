# 日常工程与局部精修复测

Windows 上使用 Chrome 157 和本机绘图引擎。选用此前已做过配色编辑的公开 UCI Iris 工程，包含 150 条观测、12 个候选版本和一处已有样式修改。用同一张数据表单独调用 Skill 的图库命令，重建 6 种关系图和可打开的工程。交接测试从编辑器复制的任务生成应用内操作 JSON，考察本机用户流程。

| 操作 | 验收范围 |
| --- | --- |
| 从文件拖入保存过的工程 | 恢复项目身份、源数据、候选图及原有手调。公开 Iris 这一次用时约 0.33 秒。 |
| 运行最终尺寸检查 | 测量 172 个对象和 10 段文字。在该尺寸和默认阈值下没有几何提示。此结果只覆盖该工程。 |
| 复制局部任务、粘贴修改 | 全程没有下载或重新选取交接文件。现有布局和分析保持原样，只新增指定 SVG 文字元素的颜色编辑。准备任务和粘贴预览这一轮分别约 58 ms 和 73 ms。 |
| 保存、重开及导出 | 一次确认只新增一条历史。重开状态相同，可导出 SVG 和 PNG。一次撤销只去掉新样式，原手调仍在，输入文件校验值一致。 |
| 图号批量对齐及重新选择 | Chrome 验证 A/B/C 直接预览、取消、保存与撤销。多选后单点 C 会重新确定交接目标，再复制任务时清单只有 C。 |

文件导入、字体刷、可编辑图件剪贴板、尺寸适配、图号以及历史记录的定向回归通过。日常耗时来自一次本机运行，不能外推到其他设备、复杂大文件或外部 AI 宿主。

## Windows 候选安装复测

在 Windows x64 隔离安装分支 `codex/studio-daily-workflow` 的 `2b13f9b` 候选包。核对安装包 SHA-256、2,704 个安装文件及分支的编辑器资源。安装版启动自检通过，Chrome 通过其本地服务加载编辑器。

- 先选 A，再选 B、C。预览将 B 的 23 pt 和 C 的 17 pt 统一为 A 的 13 pt，三者共用 A 的基线。取消恢复原值，确认后保存重开保留对齐，一次撤销恢复两处修改；A 及原项目文件保持原值。
- 使用同一公开 Iris 工程复跑拖入、质检、局部任务交接、预览、确认、保存重开、导出和撤销。保留 150 条原观测、12 个候选版本及原手调。交接无需中间文件，粘贴到预览约 62 ms；SVG 和 PNG 均成功导出。
- 测试后卸载候选。正式版本的注册信息和可执行文件校验值在安装前后相同。

## ChatGPT 和 Claude 网页交接

把同一份公开 Iris 保存工程做成验收副本，保留 A 的原手调和历史，再用同一批观察值的已有变体做 B、C。两个网页聊天都使用同一个任务，只把图号 C 从 `#20242A` 改成 `#176b5d`。聊天只收到 C 的局部任务。Studio 的浏览器验收逐条使用网页返回的实际 JSON。

| 阶段 | ChatGPT | Claude |
| --- | --- | --- |
| 首轮 | 约 12.7 KB 的任务被折成文本附件。回复使用了 `operation` 字段，并把版本放在单项内，编辑器拒绝。 | 同样被折成文本附件。复制回复中的代码，预览、一次撤销和保存重开均通过。 |
| 修复后 | 917 字节的任务直接进入正文，回复的单个 JSON 代码块通过预检。 | 相同任务直接进入正文，回复的单个 JSON 代码块通过预检。 |
| 最终本机复测 | 预览注明“小图 C · 1 项修改”，确认只增加一条历史，保存重开保留改色，一次撤销恢复。 | 同样通过。 |

确认前保存只写入已提交状态。两家最终测试均逐项核对了 A、B 和原始工程。还复测了 A 统一 B/C 图号以及 Iris 的图内文字局部修改。此次网页交接复测使用本机源码版 Studio，适用范围为这项局部改色。
