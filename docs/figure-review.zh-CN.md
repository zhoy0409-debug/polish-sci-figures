# 图形质检、结果规划与局部协作

本页对应下一稳定版源码候选。正式版是否已包含这些功能，以实际安装版本和发布记录为准。现有编辑、数据分析和导出入口继续保留。

科研 TIFF 导入、原生强度窗与大工程后台保存，见[原生 TIFF 操作指南](figure-studio-native-tiff.md)。这些源文件能力仍待最终 Windows 安装版验收。

## 在当前画布检查与调整

1. 打开工程，在顶部“导出”旁点击 **图形质检**。
2. 按目标要求设置最小字号和线宽，点击 **检查当前图形**。默认 8 pt / 0.25 pt 是通用预检阈值，不代表某本期刊的要求。
3. 点击问题旁的 **定位**，检查真实图形。文字相交使用外接框筛查，旋转文字可能需要人工排除误报。
4. 对字号问题点击 **预览调整**，或批量预览。效果直接显示在画布上；可以继续保留、立即取消，或按 Esc 取消。批量保留只产生一次撤销记录。锁定对象、复杂富文本等不能安全调整的对象会跳过。
5. 修改图形或投稿尺寸后重新检查，再保存本地检查报告。检查期间仍可编辑；若工程变化，本次结果会失效，不会覆盖新编辑。

预览期间“保存”只保存已保留的工程内容。检查和预览不联网，也不会改变原始图片、数据表或统计结果。存在未完成的数据或坐标轴重算时，先完成重算再检查。

“无法核实”表示缺少相应证据，例如一张 PNG 无法证明样本独立、配对关系、误差棒含义或比例尺标定。它既不是通过，也不是错误。复杂图片、渐变或遮挡背景不会被擅自当成白色背景作对比度判断。检查报告中的“有分析记录”不等于重新验证了模型假设。

## 比较已有排版

展开 **排版建议**，比较均衡、纵向和重点大图。系统复用现有母版、比例保护及已准备的原生尺寸候选。满意后保留，不满意取消。存在锁定内容或已裁切母版时，先使用原有母版控件逐项处理；系统不会为套版式强行移动锁定内容。

## 从已有结果规划组图

展开 **把已有结果组织成组图**，读取当前小图。逐项选择展示角色，写明该图回答的研究问题，并确认这是已经获得的结果。系统据此建议阅读顺序和排版，可以保存规划文件或在真实画布预览。

规划只使用工程中实际存在的小图，不自动补造 A–H 结果或因果链。问题或用途修改后，旧规划失效；工程变化后需重新读取小图。没有绑定数据的科研图像仍可纳入规划，其科学解释由研究者结合采集记录确认。

## 让 Skill 只改指定小图

1. 在 **与 Skill 协作（本地文件）** 导出检查清单。
2. 将清单交给本机 Skill，说明需要修改的小图与目标。清单不包含原图或测量数据表，但可能包含研究文字，应按私有科研文件管理。
3. 导入 Skill 生成的操作 JSON，核对预览，再保留或取消。

操作按目标小图的版本检查冲突。例如准备 C 的修改期间，A 的人工编辑会保留；如果 C 本身已改变，则拒绝旧操作并要求重新导出清单。任意工程覆盖、数据替换、运行代码和外部资源加载均不属于该协议。

图型切换限于同一绑定数据包内实际存在、画布一致的候选。操作文件须说明科学适用性与展示重点，界面需单独确认；需要重新计算的图型继续使用“智能选图”和现有数据工作台。完整协议与 CLI 命令见 [局部工程操作](../skills/polish-sci-figures/references/project_operations.md)。

## 大工程的配色预览

超过 1000 个图元时，配色卡先显示色板，再按可见卡片分批生成当前图的真实预览。未生成时会明确提示。离开配色面板即停止后台生成，再次进入可继续；不会用示意图冒充当前数据。

Windows 安装版、覆盖升级与本轮性能的实际验收范围见 [审计与验收记录](windows-next-stable-audit.md)。

## 复用投稿要求

通过 **投稿尺寸与导出 → 投稿配置…** 保存用户明确提供的尺寸和预检阈值，先预览，再保留或取消。**检查已保留图形**将这些阈值送入同一实际尺寸质检引擎，并报告最大高度及手动尺寸修改后的不匹配。来源不会自动联网，通用阈值不是期刊认证；参见[配置操作与范围](figure-studio-submission-profiles.md)。
