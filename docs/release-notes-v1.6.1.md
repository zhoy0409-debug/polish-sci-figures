## 中文

- **从素材到成图**。首页向导串起导入、编辑、质检和导出。可以一键跳过，稍后从顶部继续。
- **PNG 和 PDF 编辑**。PNG 可直接调整亮度和对比度。PDF 按实际内容提示可编辑对象。扫描 PDF 支持选页、整页显示调整以及独立文字标注。
- **保存与修订**。扫描页及标注可随工程恢复。保存后的撤销和重做继续生效。新编辑取代的旧重做记录会从历史中移除。
- **图号与 AI 协作**。以现有图号作参照统一字号和基线。复制指定对象的修改任务，把返回的修改从剪贴板粘贴到质检面板，预览后确认。
- **安装与更新**。Windows 安装版沿用原有安装身份和数据目录。已有安装可通过编辑器中的「更新」升级，或在保存工程并关闭编辑器后运行正式安装包。便携版完整解压后运行。安装包未签名。

## English

Figure Studio 0.2.2 is a stable Windows x64 release. The guide leads from import to export and can be paused or skipped. PNG files offer direct display adjustments. PDF import distinguishes editable text and vectors from images. Scanned pages support page selection and separate text annotations.

Saved projects retain the imported page, annotations and undo/redo history. A new edit removes superseded redo entries. You can match selected panel labels to a reference and preview scoped edits pasted from the clipboard before applying them.

The installer uses the existing per-user installation identity. Save projects before updating through Figure Studio or running Setup manually. The Windows downloads are unsigned. The same release provides the single-entry Skill ZIP and the three-skill source suite. macOS and mobile previews follow their own release schedules.
