# Windows 下一代稳定版：审计与验收记录

## 基线与发布边界

2026-10-28 实际读取 GitHub：main 为 `5f7b6c069cf80834face370e466ecb25457c1d6d`，最近主干 CI 成功；最新正式版为 Suite v1.4.26 / Figure Studio 0.1.26。原正式版安装包和历史验收附件不修改。本轮使用 `codex/windows-next-stable`，全部选定功能集成验收后只发布一次。

### 同机 5000 图元性能

使用独立的 v2 协议、Chrome 155.0.8059.85、20 次有效样本、3 轮预热和 250 ms 稳定等待；各批串行，不与构建或其他重测并行。测量浏览器事件到动画帧回调，不能解释成物理显示延迟。保留所有原始批次，不能混合 v1/v2 或挑选最有利样本。

| 选择文字，下一帧 | 39.0–39.2 ms | 43.5–43.7 ms | 38.6–40.6 ms | 42.2–49.3 ms |
