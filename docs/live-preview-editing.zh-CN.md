# 在画布中直接调整 Figure Studio

本说明介绍 Suite v1.4.26 / Windows Studio 0.1.26 的画布实时编辑。下载见[对应发行页](https://github.com/zhoy0409-debug/polish-sci-figures/releases/tag/v1.4.26)；旧编辑验收仍保留历史范围，本轮照片功能、成品与性能状态见[照片校正报告](figure-studio-photo-correction-validation.md)。

拍摄照片使用相同的显式草稿边界：**图片工具 → 一键矫正与微调**提供自动边界、标尺拉正及四角调整。预览和取消均不保留；**保留校正**才生成新版本并增加一次撤销。原图可切回，一键校色仍是可微调的全局显示参数。详见[照片操作](figure-studio-photo-correction.md)。

连续调整时保留真实草稿渲染，确认后仍执行规范校验；配色页提供完整八卡预览。使用中文输入法时，候选选词的 Enter／Esc 不等同于确认或取消整次编辑。普通文字输入结束选词后，再按普通 Enter 或移开焦点完成，按 Esc 放弃当前草稿；带明确应用按钮的工具仍须点击应用。原始表格和源图不因文字或显示调整而改写，具体操作证据见[Windows 输入法记录](windows-native-ime-acceptance.md)。

## 边框

选中图片、路径、图号或其他对象，点击画布上方的**边框**。参数面板停靠在右侧，画布保持可见。调整颜色、打印线宽、虚线、圆角或边缘范围时，直接观察图中的效果。

满意后点击**应用边框**；不满意点击**取消预览**或按 **Esc**。连续调整后应用，只增加一次撤销。打开多个图片时，混合参数表示各对象的原值不同；只修改某一个参数会保留其余差异。锁定对象保持原样。

“可见外缘”和“原图完整外缘”用途不同。裁剪图可分别查看裁剪后的边缘和原始图像范围；无法可靠映射的裁剪会显示原因，保留最后有效预览。边框线宽按最终打印 pt 解释，不随画布查看倍率改变。

## 专业坐标轴

点击**统计与坐标轴**，或双击可识别的坐标轴。开启实时预览后修改范围、刻度、线宽、文字或绘图区尺寸。本机引擎完成真实重绘后，结果显示在原画布位置；计算中保留上一个有效画面。数值输入被拒绝后，尾部事件或再次取消候选不会悄悄把范围改成“自动”。请修正数值、明确删除字段内容以请求自动范围，或取消草稿；画布保留最后有效结果。

预览期间可以继续输入。新参数取代旧请求，取消或切换目标后，迟到结果不会应用。点击**应用**保留这组设置，按 **Esc**或取消恢复开始前的图；预览本身不增加撤销记录。

原有坐标轴范围和首组间距字段、参考线颜色与宽度也采用同一路径：输入时异步预览，Enter、释放滑块或移开焦点保留，Esc 恢复。图形重绘需要本机计算时，界面显示真实的等待状态。

原生图从真实数据重绘。导入矢量图只提供已经核实的几何编辑能力；不能借拉伸伪造坐标值。锁定对象、未完成的数据修改、不适用的对数坐标或不支持的图型会说明原因。点击预览图纸会退出坐标轴草稿，回到普通元素编辑。

## 常用属性

| 操作 | 入口与保留方式 |
|---|---|
| 字号、颜色 | 选对象后使用顶部快捷栏；输入时看原位效果，Enter 或移开焦点保留，Esc 取消 |
| HEX、透明度、线宽 | 右侧属性栏；有效输入直接预览，一次输入手势结束后保留 |
| 图号改色 | 选中图号后使用顶部颜色；也可打开**查找功能**，搜索“图号改色” |
| 图号文字、位置、大小 | 右侧图号模块；同一轮调整可以即时查看并取消 |
| 字距、行距 | 顶部**文字间距**；保留原有字符格式和上下标，输入后原位查看 |
| 图片颜色与显示 | 选图片后点击**颜色与显示**；右侧停靠面板保留原图对照、直方图与显示限制，应用才保留 |
| 关联放大图 | 图片工具中的**关联总览与放大图**；先确认同源关系，再检查实际 ROI，无法匹配时不自动造框 |
| 局部放大与比例尺 | 图片工具中的对应入口；已有实时调整继续有效，物理单位需要真实标定 |
| 比例尺样式 | 右侧比例尺模块；标定、长度、位置、粗细和背景在画布预览；Esc 撤掉草稿 |
| 统计标注字号 | 统计标注模块；原位调整显示字号，保留原始分析结果 |
| 热图数值 | 热图数值模块；调整显示、精度、字号及颜色，原始矩阵不变 |
| 柱宽与组间距 | 适用图型的几何模块；连续调整后保留一次，误差数值不变 |
| 行列、跨格与图间距 | 左侧布局模块；有效数值输入直接显示空间关系，Esc 恢复 |
| 投稿尺寸与 DPI | 左侧投稿尺寸；输入宽高时保持纵横比，确认后保留真实物理尺寸 |

智能选图完成真实数据绘制后，可在候选卡中选择“在画布对照”。选图工具停靠在侧栏，主画布显示该方案的实际组图位置；取消恢复原图，应用才保留一次修改。文献中的图型对照也使用当前数据，不能把本地预览当作已经核实的论文图号或图注。

换入新数据时，原数据概况和推荐会清空。新文件读取失败后，请重新读取有效数据；系统不会继续使用上一份测量值生成方案。同一个文件可以再次选择。选图工具中的文本框保留自己的输入快捷键，普通按钮不会阻断画布的撤销和微调。

未输入完整的数字或超出范围时，控件保留草稿和最后有效画面，并说明原因。修正后继续；也可以按 Esc 取消。主题和语言切换不会把科研作品重新配色。

拖动滑块时按 Esc 会取消这一整次拖动，即使尚未松开鼠标也不会重新应用；松开后可开始下一轮调整。

支持连续数值预览的文本框可用方向键微调，Shift 加方向键使用更小步长。输入框保持原位及光标位置；正文里的字符级编辑仍沿用原来的文字编辑器。

## 保存、导出与撤销

边框、坐标轴、图片显示等带有明确“应用／保留”按钮的草稿，只有保留后才进入工程、自动保存及导出。要导出当前看到的调整，请先保留。普通属性以 Enter、释放滑块或移开焦点为一轮编辑的结束；点击其他入口使有效字段失焦时，这一轮普通属性会先保留。导出菜单会主动转移焦点，因此导出前可先按 Esc 放弃，或按 Enter 明确保留。未完成的输入不能靠失焦提交，仍保留最后有效预览。

撤销恢复一轮已保留的操作；取消仅撤掉当前草稿。切换工程、目标或撤销时，旧草稿会失效。原始 CSV/Excel、嵌入图像像素和统计结果来源不会因视觉预览改变。

图片显示调整用于展示，不能代替科学校正或信号定量。未标定的图片不能凭空生成 μm 比例尺。文献检索、图片查重和匹配仍由用户明确启动；普通视觉调整不会自动联网或扫描图片。

首次选择未标定图片时，原图实际宽度保持空白；请按原始采集记录填写。切换图片会读取该图片自己的标定与比例尺设置，不会沿用上一张图的标定。

触控与窄屏下，“调整”会在画布旁边或下方停靠，画布仍可见、可操作。选中对象后点“边框”会直接显示设置，无须再切换工作区。图层列表仍使用可关闭的抽屉。

比例尺标定对应完整原图的实际宽度。图片适配图框产生的留白不计入标定；按比例填满图框时，长度仍按完整原图计算，位置限制在可见图像内。长度、字号或线宽放不下时，请调整参数；系统不会缩短线段却保留原来的 μm 标签。无法核实的额外裁剪或遮罩暂不支持新比例尺。旧工程中的记录会保留并显示原因，修正前阻止导出，仍可继续编辑工程。
