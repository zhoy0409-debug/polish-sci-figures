# Windows 集成升级：可以怎样帮助你

这份说明介绍 Suite 1.5.0 / Figure Studio 0.2.0 Windows 集成升级。2026-11-01 用户完成安装与核心编辑协同验收并批准发布；[实测记录](qa/windows-next-stable/installed-collaborative-20261101.md)列明通过项目及尚未执行的升级、原生计时和 WB 全流程。

## 更快找到工具

六类任务打开右侧工具抽屉，同一功能只归一类；工程与图层留在左侧。按 Ctrl + K 用操作词搜索，直接跳到实际字段。重新选择画布对象保持当前工具，收起再展开可以继续草稿，保存仍排除未保留的预览。

帮助菜单提供 GitHub 反馈草稿和下载统计。反馈先预览，再由用户到 GitHub 确认；下载统计排除历史基线和登记验收，不统计用户身份或使用行为。历史净下载未知，不凑成用户数。[操作及统计口径](figure-studio-workspace-and-feedback.md)。

## 完成一张科研 Figure 的新流程

1. **先检查最终成图。** 点击顶部 **图形质检**，按实际输出尺寸检查字号、拥挤文字、裁切等问题，并定位到画布。没有原始数据或可信标定的科学信息会标为无法核实。
2. **在画布上试改。** 对受支持的字号和既有版式建议直接预览；满意后保留，不满意就取消。一次保留可一次撤销。已有数据、统计结果及锁定对象继续受保护。
3. **只修改指定部分。** 通过已有工程与局部修改文件继续协作，先查看改动范围，再应用到对应小图。其他小图的人工修改保留；来源或版本变化时会拒绝过期操作。
4. **按已确认的结果组织图组。** 规划入口整理已有结果的顺序和展示重点；信息不足时保留待确认项，不补造实验或凑满面板。

## 导入科研 TIFF 后还能继续调整

从 **导入文件** 打开受支持的 TIFF，在 **原生 TIFF 显示** 中选择实际平面，调整显示窗、伽马和显示颜色；**一键建议显示窗** 读取该平面的全图范围。参数变化直接在画布预览，可保留或取消。

保留后，在图片说明区点击 **从原始 TIFF 新建显示**，再次微调保留的原生平面。新显示放到空位置，已有图片、文字和其他编辑保留，原始文件只存一份。**下载原始 TIFF** 可取回原文件；保存和重开会核对文件与显示记录。

比较同批荧光或条带强弱时，应采用一致的显示参数。显示 PNG 不作为原生密度定量数据；打印 DPI 不等于显微标定。校正图重新读取原生平面时，不会把旧校正或比例尺自动移植过去。[支持范围与完整操作](figure-studio-native-tiff.md)随 Windows 包提供，可离线阅读。

## 保存并复用投稿要求

点击尺寸按钮，在 **投稿尺寸与导出 → 投稿配置…** 填写目标宽度、分辨率、最大高度及字号／线宽阈值。先在真实画布预览，再保留或取消；一次保留可一次撤销。配置可随工程保存，也可单独导入、导出。**检查已保留图形**使用实际成图尺寸报告问题，后续手动改尺寸会明确提示与要求不符。[完整操作说明](figure-studio-submission-profiles.md)随包提供；通用默认值不作为期刊认证。

## 大工程与已有工具

大型 SVG 的选择、配色入口及部分确认操作已减少卡顿；大图工程保存和打开改为本地后台处理，点击保存后的新编辑仍保持未保存状态。5000 图元拖动和最大图片保留仍有长任务，具体数值和全部比较批次见[验收记录](windows-next-stable-audit.md)。

智能选图、数据替换、文字与专业坐标轴、统计标注、边框、校色、透视校正、标尺拉正、局部放大、比例尺及原有导出入口继续保留。原始图片和测量数据默认留在本机；联网文献证据仍需用户主动触发。

## 安装、更新与验证范围

首次从[发行页](https://github.com/zhoy0409-debug/polish-sci-figures/releases/tag/v1.5.0)下载 Setup 安装，以后使用编辑器“更新”入口下载、校验并确认安装，无需手动解压。安装页裁切、启动、微软拼音、返回导航、边框预览和坐标轴保存重开已由用户确认；官方 0.1.26 → 0.2.0 的完整升级与实际失败恢复、新版原生 5000 图元计时仍待验证。历史 v1.4.26 资产保留。
