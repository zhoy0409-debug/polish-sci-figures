## 采用的设计方向

WB 应形成“保留原图与曝光记录 → 选取条带行 → 对齐与标注 → 检查来源 → 导出”的连贯流程。继续使用当前画布和现有裁切、标尺、文字、布局与导出控制器，不另外建产品，也不复制一套相同参数表单。专用入口应引导用户到同一实际控件；普通组图仍沿用已有六类任务。

不同曝光需要保留原始文件和明确对应，不能自动按条带强弱替用户挑选结果。不同实验组的比较不能因单独调色或选用不一致的曝光而被伪装成一致条件；显示调整记录与定量原始数据应分开。条带行旋转应是可追溯、可撤销的几何操作，不生成、补画、移动或改变单个条带的形态。

Marker 的 kDa 是分子质量标注，不能混用显微图的 μm 物理比例尺。先支持人工确认参考与标注；未知 Marker 不猜型号或数值。涉及迁移距离到分子量的估计时，另行核对标定条件和方法，不把手动标签称作测量结果。

可编辑 PPT 的验收应逐项验证图片、文字、线条和分组仍可编辑；WB 像素本身仍是原始或可追溯裁切后的栅格图像，不宣称还原成矢量条带。新流程必须检查保存重开、原图保留、撤销／重做、断网和真实 WB 样本，不以视频或合成图认证可靠性。
