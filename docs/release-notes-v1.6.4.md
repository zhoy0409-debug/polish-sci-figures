## 中文

- **任意角度标定。** 比例尺可沿水平、垂直或倾斜方向描线，按原图像素计算长度；预览线与实际测量端点一致。确认、取消和撤销沿用现有流程。
- **箭头。** 插入菜单增加单向及双向箭头；已有直线可选择起点、终点或双端箭头，继续使用原有端点拖动、样式和撤销。
- **文字空格。** 保留原生文字和新增文字的连续空格，保存工程及导出 SVG 后仍保留，左右／居中对齐不折叠字间空格。
- **TIFF 导入。** Windows、macOS 与自包含浏览器 HTML 共用“选择页面 → 画布预览 → 保留导入”。浏览器内置离线解码，支持 8／16 位灰度与 8 位 RGB 的无压缩、LZW、Deflate、PackBits TIFF，保留原文件、原始像素摘要和独立显示图。损坏或不支持的文件显示明确原因，取消不写入工程。
- **混合组合。** Shift 多选图片、文字、图号或线条可组合；点选任一成员整组移动／缩放，支持锁定、取消组合、一次撤销和保存重开。跨小图的图元组合保留各自源图。

macOS 15+ 同步提供 Apple Silicon 与 Intel 原生预览包，使用临时签名，尚未经过 Apple 公证。浏览器内无法保证保真读取的 TIFF 布局或色彩配置会提示使用桌面编辑器，不自动降位或猜测显微标定。

## English

- Calibrate from horizontal, vertical or diagonal traces in original pixel coordinates.
- Insert single/double arrows, or add arrowheads to an existing line. Endpoints, styling and undo use the existing line workflow.
- Preserve consecutive text spaces in native text, annotations, saved projects and SVG exports.
- Import supported TIFF files offline in desktop editors and self-contained browser HTML: choose a plane, preview on the canvas, then keep. Native TIFF bytes and sample digests remain separate from the display PNG. Unsupported or damaged files fail explicitly.
- Group images, native elements, panel labels and annotations across panels; select any member to move or resize the group. Lock, ungroup, undo and reopen retain group membership.

macOS previews require macOS 15+ and use ad-hoc signing without notarization. Browser decoding supports lossless classic TIFF with uint8/uint16 grayscale or RGB8; unsupported layouts/profiles direct users to the desktop editor.
