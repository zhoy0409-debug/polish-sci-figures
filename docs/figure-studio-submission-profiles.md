# 投稿配置：按真实输出尺寸预览与检查

本文对应尚未发布的 Windows 集成候选。正式安装版以发布页为准。

点击画布上方的尺寸按钮，或左侧 **投稿尺寸与导出 → 投稿配置…**。填写配置名称、要求来源和核对日期，再填写成图宽度、栅格分辨率、可选的最大高度、最小字号和最小线宽。单栏、双栏、Poster 或会议展示均可按实际要求命名；系统不为这些名称猜测尺寸。

**预览此配置**将尺寸送入原有画布渲染器；继续改变参数时，最终尺寸、像素数和字号说明同步更新。画布处于“适合窗口”时，整体缩放可能保持相似的屏幕大小，请同时查看实际毫米尺寸和最终字号。图内比例、数据、统计结果与原图均保留。**保留配置**把配置与导出尺寸一起写入工程，只增加一次撤销；**取消预览**或 Esc 恢复已保留的工程。预览期间点击保存，保存的仍是已保留状态。

**保存到本机配置**仅保存可复用的要求，不修改工程。相同名称的手动保存会更新该本机配置；可先导出 JSON 备份。**删除本机配置**不删除工程内已经保留的配置。其他窗口的最新本机配置会在打开、保存、删除或导入前重新读取。

通过 **导出配置文件／导入配置文件…** 在本机迁移要求。文件采用 `figure-studio-submission-profile/1`，也可导入 `figure-studio-submission-library/1` 配置列表；仅允许要求字段，最多 24 个配置、100 KB。导入同名但不同的配置会拒绝，不会静默覆盖。文件不包含图片、测量表或分析记录；名称、来源和备注仍可能包含私有研究文字，应自行管理。浏览器禁止本机存储时会显示错误，工程保存、预览及配置文件导出仍可使用。

保留后点击 **检查已保留图形**，系统复用图形质检的真实 SVG 测量和本地 Worker，按该配置检查最终字号与线宽，报告实际宽度、DPI、超出最大高度和阈值不匹配。问题可定位，受支持的字号修改可预览或取消。报告不会把无法测量的内容认定为通过。最大高度是检查约束，不会自动裁图、压扁或移除内容。

原有手动导出控件继续可用。若后来修改宽度或 DPI，工程保留原先的要求，下次检查明确报告不匹配；不会暗中重新应用旧尺寸。编辑后应重新检查，旧报告仅对应旧快照。实际 SVG 物理尺寸和 PNG 像素／DPI 使用原有导出器生成。

来源文本不会自动联网，也不会被当作网页执行。默认 8 pt、0.25 pt 仅沿用通用预检阈值；它们不是目标期刊要求或投稿认证。填写期刊配置时，请依据实际投稿指南或明确的编辑要求。当前功能不自动转换 CMYK、不新增字体嵌入，也不把 CLI 的 PDF 能力冒充编辑器原生 PDF 导出。栅格图片的实际分辨率不足仍由既有导出检查提示；调高 DPI 不能补回原图细节。
