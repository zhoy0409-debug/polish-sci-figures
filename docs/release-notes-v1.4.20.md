# Suite v1.4.20 · Figure Studio 0.1.20

The existing editor gains a five-part workflow bar, local command search and contextual image actions. Image borders, duplicate screening, reference display adjustment, overview/detail localization and professional axes are easier to find and operate.

- Store decorative object borders separately from source pixels, with final print pt, batch style, locks and reversible project history.
- Expose explicit duplicate preflight, local example, progress and preserved reviews; reuse bounded, expiring in-process evidence without changing screening thresholds.
- Compare original/adjusted histograms and clipped pixels, inspect image details and refine overview/detail ROIs in source coordinates before Apply.
- Re-render native numerical axes from their data for range, ticks, print geometry and appearance. Imported recognized axes retain safe presentation controls; flattened images do not acquire fictional numerical axes.
- Retain local Figure Discovery, statistical analysis, original editing tools and optional, explicitly triggered Europe PMC searches.

See [image-tool instructions](figure-studio-image-tools.md), [axes instructions](figure-studio-axes-round2.md), [real-source evaluation](scientific-image-evaluation-round2.md) and [acceptance record](figure-studio-experience-round2-validation.md). Heavy crops and Western blot strips remain known difficult cases. Independent human-labelled blind validation has not been performed. Windows acceptance belongs to this build; shared source changes do not establish new Mac/mobile device validation.

## 中文

本版在原编辑器增加五组工作入口、功能搜索与图片上下文工具，完善对象边框、图片查重、参考颜色、总览／放大图关联及专业坐标轴。

- 边框作为独立装饰保存，以最终印刷 pt 设置粗细，支持批量样式、锁定保护及可撤销工程记录。
- 查重先确认范围，提供本机示例、进度、取消和复核；增加有界、短时的进程内复用，保留原检测阈值。
- 颜色对比增加细节、直方图与截断检查；定位提供原图坐标、人工精修及明确的失败原因。
- 原生图根据真实数据重新生成坐标轴范围、刻度、印刷尺寸与外观；导入图仅使用可核实的坐标轴能力，不给压平图片虚构数值轴。
- 保留智能选图、本地统计、已有编辑能力及由用户明确触发的 Europe PMC 文献检索。

详见[图片工具指南](figure-studio-image-tools.md)、[坐标轴指南](figure-studio-axes-round2.md)、[真实来源评估](scientific-image-evaluation-round2.md)及[实际验收记录](figure-studio-experience-round2-validation.md)。重裁剪和 WB 条带仍是明确难例；用户已确认先完成工程验证，独立人工盲测准确率尚未完成。Windows 安装包按本版单独验收，未以源码测试替代 Mac／手机真机验证。
