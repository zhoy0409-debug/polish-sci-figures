# Western blot：从原图到可编辑组图

**适用：Figure Studio 0.2.0 开发候选，尚未发布。** 从顶部 **图片处理 → WB 条带处理与组图** 进入，也可按 **Ctrl+K** 搜索“WB”或“条带”。本工具用于图像展示与排版，不做灰度定量，不替用户确认样本、膜编号或曝光条件。[实际测试与剩余验收](qa/windows-next-stable/wb-workflow-20261031.md)另行记录。

## 先完成一张组图

1. **导入原图。** 点击“导入多张原图”，或将图片拖入 WB 区域；已有画布图片可点“使用画布中的图片”。TIFF 会先打开原有的原生显示窗口，选择页与显示范围后回到 WB。填写源图的曝光、样本集合／膜编号；不知道的信息留空，不按图像强弱猜测。
2. **框选完整条带行。** 在左侧原图拖出矩形。右侧选择条带行，填写蛋白名；需要换曝光时使用“本行来源／曝光”。同一框的源坐标用于新来源，须重新核对实际位置，系统不自动配准不同膜。
3. **拉正并微调。** 在属性区点“标尺拉正当前行”，沿该行拖出参考线；也可修改倾角。切回“框选条带行”，拖框或角点调整范围。原图区获得焦点后，方向键移动 1 个源像素，Shift 加速至 10 个像素。滚轮缩放，空格或中键拖动平移；“适应窗口”“原始比例”只改变查看方式。
4. **确认泳道与标注。** 在“源图泳道位置与展示顺序”建立本来源泳道边界，拖边界修正，粘贴样本名。整行展示可不设置重排；需要重排时输入如 `1,3,2`。确认后可用本来源标签建立组图列标题，再填条件矩阵和分组括号。各来源独立保存映射，不自动认定不同膜的同序号泳道对应同一样本。
5. **查看右侧真实组图。** 蛋白名、kDa、泳道标题、条件、行间距及整行等比例缩放都实时进入既有画布预览。短窗口可切换“原图／组图预览”页签。属性区独立滚动，拉正、Marker 等控件不挤在图片上方。
6. **保留或暂存。** “保留到画布”生成一个可编辑对象组，并产生一次主画布撤销记录。双击组图的图片区域可重新进入 WB；双击文字继续使用原有文字编辑器。“暂存并返回画布”保留未确认草稿，保存工程也会携带它，选中来源／蛋白行、编辑模式和展开状态一并恢复。“取消”丢弃本次 WB 草稿，恢复已确认画布；下载过的工程文件不会被改写。

在 WB 区域，顶部撤销／重做及 Ctrl+Z／Ctrl+Y 操作 WB 草稿；输入框内仍使用文字输入的撤销规则。连续参数调整会合并到短时间的草稿历史记录。返回主画布后恢复原有历史。

## 自动建议怎样使用

“自动建议…”在本机 Worker 中分析有界的显示图，叠加泳道边界／中心线、条带区域和倾角建议。原图与已确认组图不会因此改变。黄色建议线可拖动，条带上下边界也可修正；核对后才点“接受建议”。“恢复手动”会取消检测并清除建议，不清除已确认裁切。

复杂背景、弱条带、过曝和不规则泳道可能漏检或误检。已确认泳道数量与建议不同，系统拒绝静默替换样本映射；越界或超过容量的条带区域会跳过并提示数量。没有独立标注真值，当前不提供准确率、召回率或误报率认证。手动框选始终可用。

## 原图、展示与拼接的关系

| 操作 | 保留的记录与边界 |
| --- | --- |
| 导入 | 源文件字节、SHA-256、尺寸、可获得的 TIFF 页／位深／采集元数据分别保留；重复字节提示后仍保留来源 |
| 裁剪／旋转 | 记录原图四角坐标、角度、源与衍生图校验值；使用既有非生成式重采样，不补画或移动条带 |
| 显示亮度／对比度 | 同一来源所有条带行共用一套参数，与手工填写的采集曝光分开；对照和重置可立即查看未调整原图 |
| 泳道重排 | 每个片段记录原始泳道编号与源坐标；非相邻或倒序之间自动留出间隔并绘制黑色拼接线 |
| 不同来源 | 每行只能取自一张源图，来源／曝光分别记录；不会自动把不同膜融合成一张连续膜 |
| 重新编辑 | 源图与参数随工程保存；原有画布文字、样式和可对应对象编辑按稳定对象标识保留 |

高对比度可能隐藏弱条带；界面的裁切比例只是显示图采样估计，不是原始饱和／定量检查。原图对比后再决定是否采用调整。[Nature 的 WB 指南](https://www.nature.com/documents/Western_blot_guidelines.pdf)和[图像完整性政策](https://www.nature.com/commsbio/editorial-policies/image-integrity)强调完整来源、合理展示与拼接披露；软件记录不能替代实验设计与图注说明。

WB 组图仍复用原有画布的分组、移动、复制、删除、字体、对齐及撤销能力。若重新裁切改变了图片像素，旧 ROI／物理标定不能自动当作仍然有效；未改像素的图片才保留对应关联。对新裁切需重新核对这些标注，旧版本可通过历史恢复。

## kDa 标签与 Marker 估计

已知分子质量可直接填入标签。需要估计时，先填写 Marker 型号／参考，在**同一源图**点击至少两个已知 kDa 点，确认向下迁移时质量递减。然后选择近水平条带行，在该行目标位置点击“估计表观 kDa”。系统在相邻已知点之间按 log₁₀(kDa) 与源图纵坐标分段插值，不外推。

这仅是表观分子质量的展示估计，不认定蛋白身份，也不是灰度定量。当前限于倾角绝对值不超过 0.5° 的源图行；倾斜更大时使用已知标签，不能把旋转后不同横向位置的纵坐标混作迁移距离。裁切移走目标或倾角超限，会清除旧估计，避免留下过期数值。kDa 不等于显微图的 μm 比例尺。

## 格式、容量与导出

| 项目 | 当前实际支持 |
| --- | --- |
| 常规输入 | PNG、JPEG、WebP，每张不超过 20 MB；最多 16 来源、16 蛋白行、24 泳道 |
| TIFF | 复用现有本机 TIFF 解码器，原文件不超过 64 MB；受支持的 8／16-bit 灰度、RGB8，逐次选择一个页／平面。复杂多文件 OME 等范围见[原生 TIFF 说明](figure-studio-native-tiff.md) |
| 显示精度 | WB 使用 **8-bit 显示衍生图**；16-bit 原文件及页数据保留，但不承诺 16-bit WB 裁切图导出。源显示图上限 32 MP，裁切输出沿用既有引擎的像素／边长限制 |
| 工程 JSON | 原图、来源映射、参数、独立画布对象、历史与未确认 WB 草稿；重新打开可继续编辑 |
| 原图与映射 ZIP | 完整源图、保留的原生 TIFF 和来源／泳道映射 JSON；下载后可检查 SHA-256 和原生位深 |
| SVG | 既有画布导出：文字、线条、图像对象分别保留，栅格条带仍是栅格；可包含后续画布自由编辑 |
| PNG／TIF | 使用既有画布导出与尺寸设置。WB 衍生像素为 8-bit 显示，不会通过 TIF 扩展名恢复成原始 16-bit 数据；不额外锐化或美化 |
| WB 参数稿 PPTX | 一组可分别编辑的图片、文字框及线条；包含 WB 参数版式，**不包含随后在主画布自由添加的图形或局部覆盖**，此时请用 SVG 或工程 JSON |
| PDF | 当前没有 WB 原生 PDF 导出，不将浏览器截图或打印称为已验证的科研 PDF 输出 |

导出参数稿 PPTX 已用独立解析器检查结构及文字修改后保存重开，但仍需在 Windows PowerPoint 中人工检查视觉与操作。大文件导出在本机后台打包，可取消；性能、内存和实际安装版的证据边界见[验收报告](qa/windows-next-stable/wb-workflow-20261031.md)。

所有原始文件仅从用户选择的路径读取，不覆盖。建议先保存工程副本，再核对完整原图和映射 ZIP；原始采集文件仍应由用户按实验室规则另行归档。本工具无联网识别、无上传原图的 WB 服务。
