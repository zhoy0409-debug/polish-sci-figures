# 在画布旁找到工具与提交反馈

适用于尚未发布的 Windows 0.2.0 候选界面。完成本机调试后先交用户检查；**未经用户再次批准，不合并发布、不创建版本标签、不上传发行安装包**。

## 按正在做的事找工具

顶部分类打开右侧工具抽屉。每项功能只有一个分类归属；例如“行距”“字体”“统一字号”会找到同一个文字工具，但搜索“行距”会直接聚焦行距输入框。左侧仅保留工程、版本和图层。收起左右抽屉可把空间还给组图画布。

| 分类 | 工具范围 |
| --- | --- |
| 数据与图表 | 智能选图、数据表、统计分析、同数据图形、坐标轴、图例、样本点／误差棒、柱形和热图参数 |
| 文字与对象样式 | 字体字号、字符与段落格式、对象颜色／线宽／透明度、边框、图表配色 |
| 图片处理 | 照片透视校正、标尺拉正、图片校色与显示 |
| 排版与画布 | 小图布局与跨格、整图缩放、对象组合与锁定、剪贴板、对象对齐、参考线 |
| 标注与测量 | 文字与形状、面板图号、统计标注、ROI／局部放大、总览关联、真实标定比例尺 |
| 检查与导出 | 图形质检、图片查重、投稿配置、尺寸／DPI 与 SVG／PNG／TIF 导出 |

选中对象后，抽屉保留当前工具。点 **返回本类工具** 查看同类选项；点 **收起** 后再点边缘的 **工具**，回到刚才的设置。不会因重新选中画布对象就跳到另一个“属性”页面。顶部尺寸和导出按钮是同一导出工具的快捷入口。

找不到时按 **Ctrl + K**，输入“行距”“给图片加边框”“拉直”“物理比例尺”等操作词。结果会显示分类与工具名称；可用方向键和 Enter 跳转。锁定、数据合同和科学适用性检查仍然生效。未选中适用对象时，请先选中对象，不把不可用设置当成有效结果。

## 调整后保留或取消

边框、坐标轴、图片处理和已有连续预览继续使用真实画布。收起抽屉只是收起界面，**不会自动保留草稿**。回到原工具后可以继续修改或取消；保存工程时排除尚未保留的预览。保留后按一次 Ctrl + Z 撤销，Ctrl + Y 重做。不同工具的原有确认与取消说明继续适用。

照片拉直标尺用于几何方向；物理比例尺需要真实采集标定。图片显示与对象改色分开，统计分析与统计标注分开。更换入口不改变原始图像、测量数据或统计含义。

## 使用反馈

点击 **帮助 → 使用反馈**，填写不顺手的操作与希望的改进。先 **预览反馈**，核对没有私人数据后勾选公开提交确认，再点 **到 GitHub 确认提交**。编辑内容后需要重新预览确认。GitHub 需要登录，最后在 GitHub 确认才真正创建 Issue；仅打开反馈窗口或预览不会提交。

编辑器不自动附加工程、科研图片、原始测量值或日志；基础版本信息默认关闭，可自愿勾选。常见本机路径、邮箱和凭据会从草稿中遮蔽，但自由输入的科研内容仍须由提交者核对。较长内容可以保存为文本，再粘贴到 GitHub。离线时可以准备、保存反馈文本，编辑功能照常可用。

该反馈使用专属标题前缀，部署到主分支后的 Issue 路由会加上 `user-feedback` 标签并指派维护者。通知由 GitHub 及账户已有的邮箱设置发送；本轮没有代发测试反馈，也没有验证真实邮件送达。不要把填写完成或生成链接称作“反馈已提交”。

## 下载统计：验收下载不算用户下载

点击 **帮助 → 下载统计（扣除验收）**，再主动点击 **联网获取公开统计**。编辑器仅读取本仓库公开发行元数据及公开验收台账，不发送工程、图片、测量值或编辑器认证令牌，也不收集使用行为、设备身份或活跃用户数。

统计口径是 **台账起点后的正式 Windows Setup／Portable 新增下载次数，减去登记的验收下载**。不计源码包、校验文件、测试归档、草稿和预发布。下载次数不能换算为用户人数。

起点是 **2026-10-29 17:55:11 UTC（北京时间 2026-10-30 01:55:11）**。之前的全部计数已作为基线排除；历史验收无法完整追溯，所以不展示“历史净下载总数”。台账未公开、无法同步、资产被替换／删除、计数回退或扣除记录不一致时，显示待核实，不凑数或假设为零。

维护者每次真正通过发行资产下载验收后，须把该资产 ID、发生时间、次数、唯一事件编号和可公开核对的验收凭据登记到 `download-metrics-ledger.json`。重复归档的同一凭据不能重复扣除，起点前的验收也不能再扣一次。本机直接使用构建产物不产生 GitHub 下载，读取公开元数据也不产生安装包下载。半段 HTTP 探测不能未经核实就当作一次完整下载扣除。

台账经过相同核心校验后随源码更新。没有完整历史真值时，宁可保留未知，也不把验收流量称作真实用户。

## 本轮检查的边界

抽屉、搜索、预览和科研信息保留使用真实浏览器及本机计算引擎检查；受控统计响应只验证扣除规则，不是实际用户数量。此前 wn9 安装版的人工文字、边框及 5000 图元功能反馈仍有效，但 wn9 不包含本轮新界面。新包的安装实操、物理延迟、真正官方升级与失败恢复须分别验收。最新状态以[验收记录](windows-next-stable-audit.md)为准。
