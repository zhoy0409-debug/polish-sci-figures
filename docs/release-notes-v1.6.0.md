## 中文

- **画布磁吸。** 固定 A，直接拖动 B 或 C 靠近 A。辅助线出现时，拖动的图号已经贴到参照图号的文字基线。松手提交最终位置，单次拖动可以一次撤销。按住 Alt 可临时跳过磁吸。
- **导入后直接调色。** 照片进入「校色」，可编辑图表进入「换配色」。PNG 图表截图提供显示调整，并提示可导入源 SVG 或数据继续编辑图元。统计报告预览、导出及中英文界面随桌面包提供。
- **Skill 与编辑器往返。** Skill 可交付可编辑工程。在编辑器里可生成本地质检交接文件，导回后预览指定小图的修改，再确认或取消。
