## Use and compatibility

Save a project JSON before upgrading. Installed Windows editions from 0.1.9 onward can use **Updates → Download and prepare update**, wait for verification, save the project, then confirm **Install and reopen**. Versions through 0.1.8 require one manual installer run. Users already on a local 0.1.22 candidate must save, close the application and manually run the official 0.1.22 Setup: version-based updating does not offer another build with the same version. Portable copies are updated by fully extracting a new archive; they do not acquire in-app installation capability.

Unknown installation progress remains indeterminate. A brief stage may complete between UI polls; the acceptance report distinguishes backend evidence from stages actually visible in the recording. Local editing and scientific analysis continue to work without a network connection. Update checks and package downloads do not transmit research tables, images or projects.

See the [appearance/update guide](figure-studio-appearance.md), [quick start](../desktop/QUICKSTART.en.md), and [change log](../CHANGELOG.md). This release adds no new scientific-image detection accuracy claim and no new Mac/mobile hardware acceptance.
