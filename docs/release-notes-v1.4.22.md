# Suite v1.4.22 · Figure Studio 0.1.22

This local candidate adds reversible real-canvas editing across borders, axes and frequent properties, and docks image display/detail tools beside the canvas. It reuses reliable text and ROI previews and reduces unnecessary whole-figure work for eligible colour adjustments. Carbon Atelier, Pearl Pro and scientific safety rules remain. Update preparation gains a bounded local audit of actual verification, backup and installer events.

Scale bars now use the fitted full-source width rather than letterboxed SVG bounds. Preview, application and export share the same geometry; unsupported clipping and bars that do not fit are rejected without changing the physical label. Repeated axis-only redraws reuse exactly keyed local statistics, while changed data, design or methods require fresh results.

Publication is on hold at the user's request. The original Windows Setup and portable package have been built and source-matched. Actual Setup installation, browser workflows, same-version reinstall and uninstall preservation passed within the [recorded scope](qa/live-preview/windows-final17-acceptance-summary.json). The new official-version download-to-restoration flow remains unexecuted. Read the [live editing guide](live-preview-editing.en.md), [workflow acceptance](live-preview-validation.md) and [performance/update record](stable-performance-validation.md) for executed and pending checks. This is not a completed stable release.

## Use and compatibility

Save a project JSON before upgrading. Installed Windows editions from 0.1.9 onward can use **Updates → Download and prepare update**, wait for verification, save the project, then confirm **Install and reopen**. Versions through 0.1.8 require one manual installer run. Portable copies are updated by fully extracting a new archive; they do not acquire in-app installation capability.

Unknown installation progress remains indeterminate. A brief stage may complete between UI polls; the acceptance report distinguishes backend evidence from stages actually visible in the recording. Local editing and scientific analysis continue to work without a network connection. Update checks and package downloads do not transmit research tables, images or projects.

See the [appearance/update guide](figure-studio-appearance.md), [quick start](../desktop/QUICKSTART.en.md), and [change log](../CHANGELOG.md). This release adds no new scientific-image detection accuracy claim and no new Mac/mobile hardware acceptance.
