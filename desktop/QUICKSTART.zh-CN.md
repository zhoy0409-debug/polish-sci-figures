Windows安装版实操及官方0.1.25→0.1.26编辑器内升级已通过所列检查；[验收记录](../docs/qa/photo-correction/windows-0.1.26/README.md)列明数据保护、性能结果和未完成事项。

Figure Studio 用于绘制、编辑和排版科研组图。Windows 桌面版适用于 Windows 10/11（64 位），安装后无需 Codex、Python 或 API 密钥，可离线使用。

Figure Studio 是 **polish-sci-figures 的官方配套编辑器**。官方仓库 [zhoy0409-debug/polish-sci-figures](https://github.com/zhoy0409-debug/polish-sci-figures) 是本项目唯一的维护与发布入口，安装包请从该仓库的 **Releases** 下载。启动小窗口中的 **官方项目** 按钮仅在点击后打开此仓库；软件无需登录、激活或联网验证。

2026-10-18：[原官方 0.1.20 → 0.1.22 更新实测](https://github.com/zhoy0409-debug/polish-sci-figures/blob/main/docs/qa/live-preview/postrelease-20261018/README.md)已通过，原工程自动恢复并完成正常清理。此结果有明确输入范围；独立的 21 → 22 非空历史／检查点／原表草稿及正常清理也已通过。

## 安装与打开

1. **首次使用选择 Setup 安装版：** 从 [v1.4.26 官方发行页](https://github.com/zhoy0409-debug/polish-sci-figures/releases/tag/v1.4.26)下载 [polish-sci-figures-Studio-0.1.26-Setup-x64.exe](https://github.com/zhoy0409-debug/polish-sci-figures/releases/download/v1.4.26/polish-sci-figures-Studio-0.1.26-Setup-x64.exe)，直接运行并按提示安装到当前 Windows 用户，无需解压。
2. 双击桌面或开始菜单中的 **polish-sci-figures Studio**。启动小窗口显示“编辑器已就绪”后，默认浏览器会打开编辑器；也可点击小窗口里的 **打开编辑器**。
3. 页面右上角可切换中文和 English。再次点击快捷方式会打开已运行的编辑器。

**以后直接在编辑器内升级：更新 → 下载并准备更新 → 保存工程并勾选确认 → 安装并重新打开。** 受支持的安装版会下载、校验并安装后续版本，无需每次回到 GitHub 手动找包、解压或替换目录。

便携版用户须先完整解压 `polish-sci-figures-Studio-版本号-Portable-x64.zip`，再运行其中的 `Figure Studio.exe`；请保留旁边的 `_internal` 文件夹。

## 校正拍摄照片

1. 导入原始 PNG、JPEG 或 WebP，选中后打开 **图片工具 → 一键矫正与微调**。先核对自动边界，可换边界方案或拖四角微调。
2. 只是整体倾斜时，点击 **标尺拉正**，沿应水平或垂直的参考边拖线。标尺对所选范围统一旋转并内接裁剪，会替代当前四角透视；反复改线复用同一范围，不累计裁小。
3. 有可靠宽高比时明确指定；默认边长估计不是实物比例。先预览，再点 **保留校正**；**取消**或 Esc 丢弃草稿。
4. 使用 **一键校色与微调**，或 **图片颜色与显示 → 一键校色（拍摄照片）**。核对全局显示建议与截断，微调后再应用。荧光模式不提供单图自动白平衡。

**图片版本 → 保留原图／已校正**可切换原图与校正版本。重开仍从原始像素读取上次几何；比例尺与 ROI 需重新核对。详见[照片操作与限制](../docs/figure-studio-photo-correction.md)。

## 选择外观与查找工具

Studio 0.1.26 顶部**外观 → 界面主题**可选择默认深色 **Carbon Atelier** 或浅色 **Pearl Pro**。**画布周边**单独设置图纸外面的中性、深色或浅色区域；图纸保持白色，作品配色、图片像素和导出内容独立于界面偏好。当前浏览器会记住选择，无法保存时菜单会提示。

右侧标明当前选中的对象类别，优先显示相关常用设置；其他标题仍可展开。点击**查找功能**或按 **Ctrl + K**，输入“主题”“边框”“图片查重”或“轴刻度”，即可打开对应的已有工具。具体入口见[外观与更新指南](../docs/figure-studio-appearance.md#中文)，本版实际验收状态见 [0.1.26 发行说明](../docs/release-notes-v1.4.26.md#中文)。

## 留在画布中调整

0.1.26 支持[画布实时编辑](../docs/live-preview-editing.zh-CN.md)：边框和图片显示停靠在侧栏，坐标轴真实预览与应用分开；普通属性输入时可看效果，Enter／移开焦点保留，Esc 取消。带明确“保留／应用”按钮的草稿须先保留，才进入工程和导出。确认时保留真实草稿渲染，最终校验不变，配色页保留完整八卡预览。中文输入法选词时的 Enter／Esc 不结束整次编辑；完成选词后再确认或取消。实际范围见[验收报告](../docs/live-preview-validation.md)和[Windows 输入法记录](../docs/windows-native-ime-acceptance.md)。

## 不知道选哪种图：从智能选图开始

1. 在首页点击 **智能选图**；已有工程可在 **图表类型** 页打开同名入口。上传 CSV、TSV 或 XLSX（读取首个工作表，首行为列名）。数据在本机处理，桌面版无需安装 Node.js。
2. 检查数据概况与列映射，填写研究目的、样本类型和实验方法。确认原始／汇总／已有分析结果、独立／配对／纵向设计、实验单位、技术重复及嵌套关系。系统的推断会单独标明；不能用推断替代实验记录。
3. 点击 **寻找适合我的数据的方案**，比较候选卡片的适用理由、限制和自己的数据预览。通常提供 3–6 种不同展示重点的方案；科学条件不足时会更少或没有候选，并解释原因。技术重复不能直接视为独立样本，汇总数据不能重建个体分布。
4. 点击候选的 **在画布对照**，满意后选 **应用当前方案**，不满意可选 **取消画布对照**。应用后继续使用原编辑器，支持撤销、重做和保存工程。变更设计或数据后须重新生成预览。
5. 可选：展开论文证据，仅填写适合公开检索的主题、样本、实验方法关键词，再点击检索。此时才连接 Europe PMC；不要填写患者标识、实际测量值或私有工程内容。已核实图注与仅主题相关的文章分别显示，不自动下载论文图片。断网仍可本地推荐、绘图、编辑及导出。

详细条件与限制见随包 [智能选图指南](../docs/figure-discovery.md)。

## 完成第一张组图

1. 点击 **从模板开始**，按类别浏览并放大预览。选择 **使用示例开始** 后，将示例数据替换成自己的数据。也可导入已有 SVG、图片或选定的 PDF 页面。原生文字和矢量仍可编辑，图片内容仍作为图片处理；导出前请检查 PDF 的字体替代效果。
2. 在 **数据表** 中粘贴单元格（包括 Excel 区域），或导入 CSV/TSV。点击 **检查数据** 定位无效单元格，修正后点击 **更新图形**。第一行需包含模板要求的列名；**自动更新** 可按需开启。此处的模板数据编辑支持 CSV/TSV；直接导入 `.xlsx` 请使用下方“智能选图”。
3. 需要组间比较时，展开 **统计分析**，点击 **完成统计分析**（已有结果时为 **更新统计分析**）。确认自动识别的列、数据类型、独立或配对设计和实验单位。方法会按推荐顺序排列，选定即可计算并预览结果，再点击 **应用到图形**；也可连接已有比较结果。模型结果类模板需提供对应结果表。
4. 在画布中选择、拖动或框选元素，调整字体、颜色、标注及布局；可用 **撤销** 返回。设置投稿尺寸后，打开 **导出**，选择 **SVG**、**PNG** 或 **TIF**。SVG 保留矢量图形，PNG 和 TIFF 按所设尺寸和分辨率输出；放大原始低分辨率图片不能补回细节。
5. 点击 **保存** 下载工程 JSON，之后用 **项目 → 打开工程** 继续编辑。SVG/PNG/TIFF 是成图，工程 JSON 才是包含编辑状态、数据和版本记录的备份。

当前数据建立的统计分析会随有效数据更新重新计算；外部比较结果或拆分分面保留的结果，在对应数据改变后需按页面提示重新连接或更新。未完成或无效的数据修改不会覆盖上一版有效图形。

继续添加图形时，将文件夹中的 PDF、SVG、PNG、JPEG 或 WebP 拖入画布、顶部或侧栏。绿色格子显示实际导入位置，已有图形的格子会单独提示保留；多份文件依次处理，PDF 逐份预览并选页。拖入一份工程 JSON，确认后打开整个工作区。拖入 CSV/TSV 会进入数据流程。双击可编辑文字修改，点击外部即可完成；编辑器中建立的组合可用**取消组合**拆开。导入 SVG 的文字、图形可直接点选，原有变换和裁剪保留。

统计样式和条件表统一在**标注**页。如需参考已发表图形，展开**图表类型 → 文献作图实例**，点击**查找文献实例**；只有主动检索时才连接 Europe PMC，发送图型词和手动填写的可选主题，研究数据留在本机。[图注核对与数据预览说明](../README.zh-CN.md#文献作图实例)。

**调整布局和图形组件：** 拖动网格边界设置行高或列宽；在**属性 → 按组成部分统一调整**中选择要修改的部分，设置作用于当前小图或整张组图。需要延伸可识别数值轴时，选中轴并拖动端点，刻度与数字沿原映射补充，数据位置不变；可用**撤销**恢复。

选中文字即可使用**文字间距**，或用**格式刷**复制其文字样式；图形颜色单独使用**吸色笔**。Shift + 点击多选小图后，可一起对齐或按 **Delete** 删除。图号可与图内元素一起选择；完成的内容先锁定，再调整网格，解锁后继续编辑。选空格删除时，只移除整条空白行或列。

点击**格式刷**旁的箭头，选择要复制的样式，以及保留导入字体还是换为 Arial／Times New Roman；保留字体名称不会安装缺失字体。选中可编辑文字或图形后点**复制**，再点**粘贴元素**即可在当前小图复制；先选其他小图或空格再粘贴，可改变目标。已有图形、母版边界和行列尺寸保留。快速字号在离开输入框时应用。详见[编辑指南](../README.zh-CN.md#局部放大与软件更新)。

点击对齐图标，展开左、中、右及顶部、居中、底部对齐；水平和垂直等距分布需至少三个可编辑对象。对齐后继续按方向键微调，按住 Shift 使用较大的步长，随后可接着缩放或修改。

## 保存、退出与升级

**重要工程请定期点击“保存”，把 JSON 下载到自己的文件夹。** 还可在 **项目 → 项目与预设** 中查看组图、下载整个总览备份。

应用设置、工作页及日志位于 `%LOCALAPPDATA%\Figure Studio`。自动保存、最近工程和项目总览记录保存在所用浏览器的本地存储中，和应用文件夹是两处不同的位置。清除浏览器网站数据、使用隐私窗口、切换浏览器或用户配置，都可能使这些记录丢失或不可见；仅备份应用文件夹不能代替下载工程 JSON。

关闭浏览器标签页不会停止本机服务。结束使用时，在 Figure Studio 启动小窗口点击 **关闭服务并退出**；关闭该小窗口也会退出。正在计算的任务会等待完成。

**从 0.1.8 或更早版本升级：** 保存工程 JSON，关闭 Figure Studio，再运行 0.1.26 安装程序。旧版更新入口只能打开下载链接，不能替你安装这次升级。

**已经使用本地 0.1.26 候选版？** 用正式构建替换本地 0.1.26 候选版时，请保存工程、关闭 Figure Studio，再手动运行上方官方安装包覆盖。更新器按版本号判断，不会自动提供另一个同版本构建。

**已经安装 0.1.9–0.1.25？** 可使用应用内更新流程；若 0.1.9 因路径过长而在准备阶段失败，请保存工程、关闭 Figure Studio，再手动运行当前 0.1.26 安装程序。0.1.26 保留 0.1.10 加入的长路径修复。

**安装 0.1.26 后获取后续更新：** 打开**更新**，选择**下载并准备更新**，等待下载和完整性校验。保存工程，勾选已保存、可以关闭编辑器的确认项，再选择**安装并重新打开**。安装程序沿用受支持的当前应用位置，成功后重新打开 Figure Studio；无需自行解压或替换文件。未经确认不会启动安装，也不会绕过 Windows 安全提示。

**便携版、源码运行或未识别的自定义副本：** 不会被强制覆盖。若希望以后在编辑器内升级，先保存工程 JSON，退出旧副本，从官方入口下载并运行一次 Setup，使用默认安装位置，再从桌面或开始菜单的正式快捷方式启动；可用**项目 → 打开工程**载入备份。安装后仍提示不支持时，按具体错误处理，不绕过安装位置和安全检查。上述旧版本、同版本候选版及长路径例外仍适用。

更新窗口的猫狗跟随真实下载、校验与安装阶段。下载到 100% 后仍需完整性校验，等到**准备好了，可以安装**再确认安装。取消勾选**角色动画（遵循系统降动效设置）**即可保持静态，进度与按钮继续更新；系统降动效偏好也会停止动作。安装程序接手后，正常关闭旧服务保留中性的安装提示；接手前的连接异常提供**重新获取进度**入口。

正常升级或卸载不会主动删除上述用户数据目录；浏览器记录由浏览器维护，不保证永久保留。应用尚未进行数字签名的版本可能显示“未知发布者”或 Windows 安全提示，请核对下载来源和发布方提供的校验值。

发布页的 SHA-256 校验值用于核对文件是否一致，不是发布者数字签名。官方标识和下载入口方便识别维护版本，不保证软件无法被复制或重新分发；使用与分发条件以随附许可证为准。
