# Figure Studio 使用入门

Figure Studio 用于绘制、编辑和排版科研组图。Windows 桌面版适用于 Windows 10/11（64 位），安装后无需 Codex、Python 或 API 密钥，可离线使用。

Figure Studio 是 **polish-sci-figures 的官方配套编辑器**。官方仓库 [zhoy0409-debug/polish-sci-figures](https://github.com/zhoy0409-debug/polish-sci-figures) 是本项目唯一的维护与发布入口，安装包请从该仓库的 **Releases** 下载。启动小窗口中的 **官方项目** 按钮仅在点击后打开此仓库；软件无需登录、激活或联网验证。

## 安装与打开

1. 下载 [Windows 安装包](https://github.com/zhoy0409-debug/polish-sci-figures/releases/download/v1.4.13/polish-sci-figures-Studio-0.1.13-Setup-x64.exe)，运行后按提示安装到当前 Windows 用户。
2. 双击桌面或开始菜单中的 **polish-sci-figures Studio**。启动小窗口显示“编辑器已就绪”后，默认浏览器会打开编辑器；也可点击小窗口里的 **打开编辑器**。
3. 页面右上角可切换中文和 English。再次点击快捷方式会打开已运行的编辑器。

便携版用户须先完整解压 `polish-sci-figures-Studio-版本号-Portable-x64.zip`，再运行其中的 `Figure Studio.exe`；请保留旁边的 `_internal` 文件夹。

## 完成第一张组图

1. 点击 **从模板开始**，按类别浏览并放大预览。选择 **使用示例开始** 后，将示例数据替换成自己的数据。也可导入已有 SVG、图片或选定的 PDF 页面。原生文字和矢量仍可编辑，图片内容仍作为图片处理；导出前请检查 PDF 的字体替代效果。
2. 在 **数据表** 中粘贴单元格（包括 Excel 区域），或导入 CSV/TSV。点击 **检查数据** 定位无效单元格，修正后点击 **更新图形**。第一行需包含模板要求的列名；**自动更新** 可按需开启。如需导入 `.xlsx` 文件，请先从电子表格软件导出 CSV/TSV。
3. 需要组间比较时，展开 **统计分析**，点击 **完成统计分析**（已有结果时为 **更新统计分析**）。确认自动识别的列、数据类型、独立或配对设计和实验单位。方法会按推荐顺序排列，选定即可计算并预览结果，再点击 **应用到图形**；也可连接已有比较结果。模型结果类模板需提供对应结果表。
4. 在画布中选择、拖动或框选元素，调整字体、颜色、标注及布局；可用 **撤销** 返回。设置投稿尺寸后，打开 **导出**，选择 **SVG**、**PNG** 或 **TIF**。SVG 保留矢量图形，PNG 和 TIFF 按所设尺寸和分辨率输出；放大原始低分辨率图片不能补回细节。
5. 点击 **保存** 下载工程 JSON，之后用 **项目 → 打开工程** 继续编辑。SVG/PNG/TIFF 是成图，工程 JSON 才是包含编辑状态、数据和版本记录的备份。

当前数据建立的统计分析会随有效数据更新重新计算；外部比较结果或拆分分面保留的结果，在对应数据改变后需按页面提示重新连接或更新。未完成或无效的数据修改不会覆盖上一版有效图形。

继续添加图形时，使用工作区的导入入口，或拖入 PNG、JPEG、WebP、SVG；多份文件会依次处理，PDF 逐份提示选择页面。拖入 CSV/TSV 会进入数据流程。双击可编辑文字修改，点击外部即可完成；编辑器中建立的组合可用**取消组合**拆开。导入 SVG 的文字、图形可直接点选，原有变换和裁剪保留。

统计样式和条件表统一在**标注**页。如需参考已发表图形，展开**图表类型 → 文献作图实例**，点击**查找文献实例**；只有主动检索时才连接 Europe PMC，发送图型词和手动填写的可选主题，研究数据留在本机。[图注核对与数据预览说明](../README.zh-CN.md#文献作图实例)。

**调整布局和图形组件：** 拖动网格边界设置行高或列宽；在**属性 → 按组成部分统一调整**中选择要修改的部分，设置作用于当前小图或整张组图。需要延伸可识别数值轴时，选中轴并拖动端点，刻度与数字沿原映射补充，数据位置不变；可用**撤销**恢复。

## 保存、退出与升级

**重要工程请定期点击“保存”，把 JSON 下载到自己的文件夹。** 还可在 **项目 → 项目与预设** 中查看组图、下载整个总览备份。

应用设置、工作页及日志位于 `%LOCALAPPDATA%\Figure Studio`。自动保存、最近工程和项目总览记录保存在所用浏览器的本地存储中，和应用文件夹是两处不同的位置。清除浏览器网站数据、使用隐私窗口、切换浏览器或用户配置，都可能使这些记录丢失或不可见；仅备份应用文件夹不能代替下载工程 JSON。

关闭浏览器标签页不会停止本机服务。结束使用时，在 Figure Studio 启动小窗口点击 **关闭服务并退出**；关闭该小窗口也会退出。正在计算的任务会等待完成。

**从 0.1.8 或更早版本升级：** 保存工程 JSON，关闭 Figure Studio，再运行 0.1.13 安装程序。旧版更新入口只能打开下载链接，不能替你安装这次升级。

**已经安装 0.1.9 或更新版本？** 可使用应用内更新流程；若 0.1.9 因路径过长而在准备阶段失败，请保存工程、关闭 Figure Studio，再手动运行上方的 0.1.13 安装程序。0.1.13 已包含 0.1.10 加入的长路径修复。

**安装 0.1.13 后获取后续更新：** 打开**更新**，选择**下载并准备更新**，等待下载和完整性校验。保存工程，勾选已保存、可以关闭编辑器的确认项，再选择**安装并重新打开**。安装程序沿用当前应用位置，成功后重新打开 Figure Studio。便携版仍需手动替换文件。未经确认不会启动安装，也不会绕过 Windows 安全提示。

正常升级或卸载不会主动删除上述用户数据目录；浏览器记录由浏览器维护，不保证永久保留。应用尚未进行数字签名的版本可能显示“未知发布者”或 Windows 安全提示，请核对下载来源和发布方提供的校验值。

发布页的 SHA-256 校验值用于核对文件是否一致，不是发布者数字签名。官方标识和下载入口方便识别维护版本，不保证软件无法被复制或重新分发；使用与分发条件以随附许可证为准。
